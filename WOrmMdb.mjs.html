/**
 * 操作Access mdb資料庫
 *
 * 註: 主鍵欄位取自opt.pk，預設為id，支援由呼叫端指定
 * 註: 本套件經connMDB.exe操作Windows內建之Jet 4.0引擎，僅支援.mdb(Jet4)不支援.accdb
 * 註: 主鍵之[命中]一律以Jet引擎之判定為準: Jet之字串等值不分大小寫(含非ASCII)、忽略尾端半形空白、
 * 忽略全半形寬度與平片假名、ß視同ss(已實測); selectByPk、insertBulk、save、del之判定皆交Jet以=語句為之,
 * insert之撞鍵核對以快速鍵對應, 對不上者亦以=語句交Jet判定; 主鍵之定位不依賴IN之結果(Jet對長字串之IN與=不等價)
 * 註: 主鍵值送出前依主鍵欄型別正規化(見pk.mjs之normPk): 字串類主鍵欄之有限數字以String(v)處置(與w-serv-orm一致),
 * 數值類主鍵欄之標準數字字串轉為數字; 型別不符者selectByPk回null、insert/insertBulk/save於寫入前reject、del該筆ok為0
 * 註: 字串類主鍵超過255字元、含NUL或非良構UTF-16者不可能存在於資料表, 讀取類視為未命中且不送Jet
 * (Jet對超過255字元之字面值於SELECT/DELETE會截斷後比對, 送出將命中或刪除另一列)
 * 註: select與delAll之條件(find)僅支援系列白名單(欄位等值、$eq $ne $gt $gte $lt $lte $in $nin、文件層$and $or; 詳見select與delAll之說明), 白名單外一律整批reject;
 * 主鍵等值類條件($eq、$ne、$in、$nin及隱含等值)改寫為由Jet判定之命中列, 不以JS仿製之等值鍵判定;
 * 主鍵之範圍運算子與非主鍵欄之條件依記憶體sqlite(字串欄為NOCASE); $ne、$nin含無效主鍵值reject; select回傳Jet原列, 內容與selectByPk相同
 * 註: 主鍵欄須為文字或數值型, Jet之GUID型別與DATETIME型別之主鍵欄不支援
 * 註: insert與save之原子性倚賴資料表主鍵欄位具唯一約束(PRIMARY KEY)，資料表建立時須含之
 * 註: Jet DATETIME以本地時間分量存放，可存放範圍為本地年100–9999；寫入(insert、insertBulk、save)之Date(任何欄位，含Invalid Date)
 * 本地年小於100或大於9999、或DATE/DATEONLY欄之字串含零填充之小年份(獨立數字串達3位以上而值小於100，如0050-06-15、06/15/0050、June 15, 0050、050-06-15)者，
 * 整批reject且資料庫不變(發出一次error事件，不發change事件；save亦然，含autoInsert為false與不會寫入之列，不降為逐筆ok為0)，
 * 訊息為invalid data: date is not a valid time in years 100-9999 at [data[索引].欄位名]，不回顯值(曆法不存在者如2026-02-30T00:00:00亦同訊息)。
 * 原因: Jet對年0–99依兩位數年規則靜默改年(0050→1950)而不報錯。既有被改年之資料不遷移。兩位數年(如6/15/50)為Jet文件化之寫法，不在此限
 * 註: DATE/DATEONLY欄收到select回傳形式之無時區字串(yyyy-MM-ddTHH:mm:ss或空格分隔，可含小數秒)時驗曆法後正規化為牆上時間yyyy-MM-dd HH:mm:ss再寫入(小數秒捨去，Jet無法經文字寫入；不經Date，故夏令跳過之時刻往返不變)，
 * 令select取出之列可原樣save/insert；含Z或偏移之ISO 8601字串轉為Date(瞬間無歧義)後依本地分量寫入；純日期yyyy-MM-dd驗曆法後原樣交Jet；
 * 字串包裝物件、陣列等非Date物件以String(v)取字串(同寫出時之序列化)判定；其餘字串、數值、布林交Jet判定(現況行為不變)；change事件之data帶正規化值
 * 註: 字串之預檢依model欄型(DATE/DATEONLY)判定，model須把Jet之DATETIME欄宣告為DATE或DATEONLY(宣告為TIME或STRING者字串不預檢)；
 * 資料列之Function或Error列、覆寫valueOf/constructor/Symbol.toStringTag之Date子類別不在保證範圍(已知限制LD5、LD6)；原型鏈上帶getter之列(類別實例等)自第66項起於呼叫當下攤平為純資料(見字串良構檢核之說明), 不再有「兩次讀值可能不同」之問題
 * 註: DATE欄之日期條件以牆上時間(浮動時間)比較，與主機時區無關，負偏移時區主機含9999年末日哨兵列時亦正確(原已知限制LF8，第87項B4已解；見select之使用須知6.)
 * 註: 字串良構檢核(第66項，見CLAUDE_rulebook.md之R-WF)：本套件與Jet之間經UTF-8交換資料，孤立代理碼元(String.prototype.isWellFormed()為false)會被改寫為U+FFFD，
 * 使不同主鍵寫成同一鍵、寫入值與讀回值不同，故一律拒收。(1)主鍵(字串)不得含NUL或孤立代理；(2)寫入資料(insert、insertBulk、save)之鍵名與字串值
 * (含巢狀物件、陣列元素、Map與Set等；model外之鍵亦檢)不得含孤立代理，值之NUL不拒；(3)opt.db、opt.cl、opt.url、opt.storage、opt.pk不得含孤立代理，建構時throw invalid opt.名稱: string contains lone surrogate。
 * 處置與無效主鍵同形：insert與insertBulk於寫入前整批reject(先發一次error事件，不發change，不寫任何一筆，以索引最小者為準)；
 * save與del該筆ok為0並附err，同批其餘筆照常(del原為靜默回ok為1，save的autoInsert為false時原亦靜默)；selectByPk回null；select與delAll之find依既有invalid find。
 * 訊息為固定詞彙且不回顯值：invalid id: string contains lone surrogate at [data[索引].主鍵欄]、invalid data: string contains lone surrogate at [路徑]（主鍵含NUL時原因為string contains NUL）。
 * 檢核先於初始化(匯入model)與任何讀取、寫入、刪除，作用於呼叫當下之複本且只使用該複本(insert、insertBulk、save、del於呼叫時複製數據並把非純物件之列攤平為只含自有資料屬性之純物件，
 * 可列舉屬性[自有與繼承]與原型鏈上之存取器各讀一次並深複製其值；建構時opt亦只讀一次並複製，不再寫回預設值)，不隨opt.autoGenPk改變；
 * 另於字串進入SQL文字之出口(escVal、escId)再檢一次作最後防線；String包裝物件以其字串值檢核並寫成一般字串(Jet只存文字)，列內巢狀之類別實例與Map之物件鍵為共用參照(已知限制)。
 * 既有資料不遷移：修正前經本套件寫入之孤立代理已被改寫為U+FFFD且無從還原，檢出法見README。
 * 註: Jet之字串等值由其排序規則決定(不分大小寫、忽略尾端半形空白、全半形、假名與增補平面字元等)，良構字串亦可能相等：'a'、'a'+emoji、'a'+U+FFFD為同一主鍵
 * (selectByPk('a'+emoji)命中'a'，del可刪到'a')，與大小寫同屬設計，套件不改變(要精確比對須由資料庫端另處理)
 *
 * @class
 * @param {Object} [opt={}] 輸入設定物件，預設{}
 * @param {String} [opt.url='mdb://username:password'] 輸入連接資料庫字串，資料庫僅可選'mdb'，預設'mdb://username:password'。解析失敗時建構函式拋出之Error訊息為`原因, opt.url[遮罩後連線字串]`(前綴與Error型態不變)：://之後一律不回顯(回顯為`scheme://***`，連線字串無主機，@之後可能是密碼之後半)，無://者為`***`，scheme須為識別字否則為`***`；`dialect[…] is not mdb`之dialect於無://或不合scheme樣式時亦為`***`
 * @param {String} [opt.storage='./worm.mdb'] 輸入mdb資料庫檔案位置字串，預設'./worm.mdb'
 * @param {Boolean} [opt.useEncryption=false] 輸入是否使用加密保護，型別為布林值，預設false
 * @param {String} [opt.db='worm'] 輸入使用資料庫名稱字串，mdb並不需要給只是配合w-orm系列統一設定，預設'worm'
 * @param {String} [opt.cl='test'] 輸入使用資料表名稱字串，預設'test'
 * @param {String} [opt.fdModels='./models'] 輸入資料表設定檔所在資料夾字串，預設'./models'
 * @param {String} [opt.modelType='js'] 輸入資料表設定檔類型字串，可有'js'、'json'，預設'js'
 * @param {Boolean} [opt.logging=false] 輸入是否紀錄記憶體過濾表實際執行的sql指令布林值，預設false。為true時預設只輸出敘述種類(如SELECT)，不輸出sql全文：select之過濾表以INSERT寫入各列欄位值、以WHERE帶入條件值，需搭配opt.logDetail或opt.funLog才取得sql全文，有洩漏個資之風險，僅供除錯使用(送往Jet引擎之語句不在此紀錄)
 * @param {Boolean} [opt.logDetail=false] 輸入是否還原診斷輸出之完整細節布林值，預設false，型別錯誤者視同false。診斷輸出(console)預設只含固定標籤與不含個資之摘要(不含資料值、id、後端錯誤原文、路徑)；為true時還原為含細節的輸出(訂閱函數拋出之錯誤、opt.logging之sql全文、genModelsByTabs之檔案路徑與存檔錯誤等)，有洩漏個資之風險，僅供除錯使用。連線字串與帳密於任何情形皆以***遮罩
 * @param {Function} [opt.funLog=null] 輸入診斷輸出函數(label, safe, detail)，預設無，型別錯誤者視同未給。給予時診斷輸出只交給它而不寫console：label為固定標籤字串，safe為不含個資之摘要物件(可能為undefined)，detail為完整細節之遮罩拷貝(可能無此引數；連線字串與帳密已以***遮罩；深度與大小有上限，函數、二進位資料、Map/Set、存取器以標記字串代替，不沿用原型，不執行使用端程式)，供使用端遮罩後轉送。函數拋錯或回傳reject之promise皆被吞下，不影響各操作之結果
 * @param {String} [opt.pk='id'] 輸入數據主鍵字串，預設'id'
 * @param {Boolean} [opt.autoGenPk=true] 輸入若數據主鍵欄位沒給時則自動給予隨機uuid，型別為布林值，預設true
 * @param {Boolean} [opt.useStable=true] 輸入是否使用穩定模式，使用佇列管理同時只能進行一種操作故會犧牲效能，型別為布林值，預設true
 * @returns {Object} 回傳操作資料庫物件，各事件功能詳見說明
 */
function WOrmMdb(opt = {}) {
    let ss
    let u


    //opt於建構開始時讀一次並複製為內部設定, 其後預設、檢核、解析與所有操作只使用此複本(第66項, 檢查之值即使用之值):
    //呼叫端其後改動原opt, 或存取器每次回傳不同值, 皆不影響本實例; 預設值亦不再寫回呼叫端之opt
    //取全部可列舉屬性(自有與繼承)與本套件讀取之選項名稱(無條件讀取, 不以in判定: 保留修改前一般屬性存取讀得到之行為, 如類別之getter、defineProperty定義之不可列舉選項、僅有get陷阱之Proxy),
    //每個名稱只讀一次, 以defineProperty定義(名稱為__proto__時不改動原型); 非物件之opt與修改前同為錯誤
    if (opt === null || typeof opt !== 'object') {
        throw new TypeError('invalid opt: not an object')
    }
    {
        let names = new Set()
        for (let k in opt) {
            names.add(k)
        }
        for (let k of ['url', 'db', 'cl', 'fdModels', 'modelType', 'logging', 'logDetail', 'funLog', 'pk', 'autoGenPk', 'useStable', 'storage', 'useEncryption']) {
            names.add(k)
        }
        let o = {}
        for (let k of names) {
            Object.defineProperty(o, k, { value: opt[k], writable: true, enumerable: true, configurable: true })
        }
        opt = o
    }


    //default
    if (!isestr(opt.url)) {
        opt.url = 'mdb://username:password'
    }
    if (!isestr(opt.db)) {
        opt.db = 'worm'
    }
    if (!isestr(opt.cl)) {
        opt.cl = 'test'
    }
    if (!isestr(opt.fdModels)) {
        opt.fdModels = './models'
    }
    if (!isestr(opt.modelType)) {
        opt.modelType = 'js'
    }
    opt.logging = (opt.logging === true)
    if (!isestr(opt.pk)) {
        opt.pk = 'id'
    }
    if (!isbol(opt.autoGenPk)) {
        opt.autoGenPk = true
    }
    if (!isbol(opt.useStable)) {
        opt.useStable = true
    }
    if (!isestr(opt.storage)) {
        opt.storage = './worm.mdb'
    }


    //儲存位址名稱(opt.db、opt.cl、opt.url、opt.storage)與主鍵欄名(opt.pk)含孤立代理碼元者建構時即拋出(第66項, 見CLAUDE_rulebook.md之R-WF):
    //資料表名、欄位名與檔案路徑經UTF-8轉換後孤立代理碼元被改寫為U+FFFD, 不同名稱會指向同一個資料表、欄位或同一個mdb檔(opt.pk亦會進入錯誤訊息之路徑);
    //須先於opt.url之解析(其錯誤訊息會回顯opt.url); 訊息為固定詞彙且不回顯值, 此處不檢NUL(不屬本規則)
    for (let k of ['db', 'cl', 'url', 'storage', 'pk']) {
        let why = chkOrmStr(opt[k], { nul: false })
        if (why !== null) {
            throw new Error(`invalid opt.${k}: ${why}`)
        }
    }

    opt.storage = path.resolve(opt.storage)
    if (!isbol(opt.useEncryption)) {
        opt.useEncryption = false
    }


    //ee, 採wsemi之evem(即eventemitter3), 其於'error'無監聽者時僅回傳false而不拋出,
    //故本套件之操作行為不因呼叫端有無註冊監聽而改變; Node內建之EventEmitter具該拋出語義, 不可用
    let ee = evem()


    //opt.url解析失敗一律拋出, 因其屬呼叫端未履行契約, 且解析失敗後各函數皆無從運作,
    //建構為同步而無從以Promise.reject回報, 拋出即為reject之同步對應;
    //若僅console.log而回傳未綁定各函數之ee, 錯誤不經任何管道抵達呼叫端, 呼叫端僅得到
    //[w.select is not a function]之無關訊息, 與本規格[錯誤不得靜默]之通則相違
    //訊息前綴與Error型態不變, 回顯之opt.url經maskUrl(R-DIAG-06): 帳號與密碼不出現(未捕獲時Node會把訊息印到stderr); maskUrl為純函數, 不依賴尚未建立之diag
    let throwUrlErr = (msg) => {
        throw new Error(`${msg}, opt.url[${maskUrl(opt.url)}]`)
    }


    //dialect
    let dialect
    ss = split(opt.url, '://')
    dialect = get(ss, 0, null)
    if (!dialect) {
        throwUrlErr('no dialect in opt.url')
    }
    if (dialect !== 'mdb') {
        //dialect取自第一個://之前, 無://時即整串opt.url(可能含帳密), 故經maskDialect(R-DIAG-06)
        throwUrlErr(`dialect[${maskDialect(opt.url)}] is not mdb`)
    }
    u = get(ss, 1, '') //另存給後面使用


    //username, password
    let username
    let password
    ss = split(u, '@')
    u = get(ss, 1, '') //另存給後面使用
    ss = get(ss, 0, '')
    ss = split(ss, ':')
    if (size(ss) !== 2) {
        throwUrlErr('invalid username or password in opt.url')
    }
    username = get(ss, 0, '')
    password = get(ss, 1, '')
    if (opt.useEncryption) {
        if (username === '') {
            throwUrlErr('invalid username in opt.url')
        }

    /**
     * 寫入或刪除前逐筆檢核主鍵與資料之良構(第66項, 見CLAUDE_rulebook.md之R-WF)
     *
     * 註: 主鍵字串含NUL或孤立代理、資料之鍵名與字串值(含巢狀與陣列元素)含孤立代理者不合格; 值之NUL不拒; 判定單一擁有者為wsemi之chkOrmStr與chkOrmData
     * 註: 同一筆主鍵先於資料, 逐筆結果各自保留: insert與insertBulk取索引最小者整批reject, save與del該筆ok為0且其餘筆照常
     * 註: 訊息為固定詞彙且不回顯值: invalid id: 原因 at [data[索引].主鍵欄]、invalid data: 原因 at [路徑]
     * 註: 檢查之值即使用之值: 輸入須為呼叫當下之快照(見snap與flatRow: 各列已攤平為只含自有資料屬性之純物件, 主鍵與各欄位值皆已讀過一次，
     * 其後不再有存取器或原型鏈上之讀取, 呼叫端其後改動原物件、原型或存取器之副作用皆不影響本函數所檢與其後所寫);
     * 巢狀值內若仍有存取器(巢狀之類別實例)則於走訪時被呼叫, 其輸出若成為字串寫入SQL文字, 由getCmd.mjs之escVal最後防線把關, 令任何路徑皆不可能產出含孤立代理之常值
     * 註: 須先於初始化(匯入model)、讀取與寫入; 檢核與讀取過程拋錯(存取器或Proxy陷阱拋出)原樣拋出, 由呼叫端以整批性錯誤處理
     *
     * @ignore
     * @param {Array} rows 輸入數據陣列(呼叫當下之快照)
     * @param {Boolean} withData 輸入是否一併檢核資料(insert、insertBulk、save為true, del為false)
     * @returns {Array} 回傳與rows等長之陣列, 合格者為null, 不合格者為訊息字串
     */
    function chkWf(rows, withData) {

        return map(rows, (v, k) => {

            //pk, 先於資料
            let pkv = get(v, opt.pk)
            let why = chkPkWf(pkv)
            if (why !== null) {
                return `invalid id: ${why} at [data[${k}].${opt.pk}]`
            }

            //data
            if (withData) {
                let r = chkOrmData(v, { root: `data[${k}]` })
                if (r === null && v !== null && typeof v === 'object' && v[KEY_CONT] !== undefined) {
                    r = chkOrmData(v[KEY_CONT], { root: `data[${k}]` })
                }
                if (r !== null) {
                    return `invalid data: ${r.reason} at [${r.path}]`
                }
            }

            return null
        })
    }

    /**
     * 把單筆數據之主鍵定為唯讀(第66項, 見CLAUDE_rulebook.md之R-WF-04)
     *
     * 註: 檢核與正規化後主鍵即為其後預讀、更新、刪除與撞鍵核對所用之值; 寫入語句產生過程會呼叫使用者程式碼(自訂toString等),
     * 其副作用若改動同批另一列之主鍵, 後續讀取會得到不同鍵而更新或刪除他列; 定為唯讀後此類賦值於嚴格模式下拋錯(整批性錯誤, 產生寫入語句之階段尚未寫入任何一筆)
     *
     * @ignore
     * @param {*} v 輸入單筆數據
     * @returns {*} 回傳輸入
     */
    function lockPk(v) {
        if (v !== null && typeof v === 'object') {
            try {
                Object.defineProperty(v, opt.pk, { writable: false, configurable: false })
            }
            catch (err) {}
        }
        return v
    }


    /**
     * 檢查並補齊單筆數據之主鍵
     * autoGenPk為true時未帶有效主鍵者自動產生，為false時往外拋
     * 註: 未帶有效主鍵屬呼叫端未履行契約而非某一筆資料本身之問題，故為整批性錯誤而不降級為該筆ok為0，
     * 若降級為逐筆結果，呼叫端易於整批resolve之下漏看，使[忘了給主鍵]靜默變成[少寫了幾筆]
     * 註: 本函數須於任何寫入之前一次對全部數據完成，令拋錯時同批之有效筆數亦不會被寫入
     * 註: 自動產生之主鍵值為字串，故補值前檢查主鍵欄位確為字串類型，不符者以明確訊息拋出，
     * 而非任由資料庫回報型別錯誤; 本套件之model定義於手上得知主鍵型別，故不適用T6之[套件無從得知主鍵型別]例外
     * 註: 有效主鍵依主鍵欄型別正規化後就地寫回數據(見pk.mjs之normPk)，令寫入值與其後各函數之比對值一致;
     * 型別不符者為呼叫端未履行契約，比照T6以整批性錯誤拋出(比照w-orm-postgresql之處置);
     * 不可能存在者(字串類主鍵超過255字元)於insert與insertBulk亦整批拋出，
     * 於save則回傳cannot為true，由save將該筆定為ok為0(autoInsert為false則n為0)而不送Jet
     * 註: 含NUL或孤立代理之主鍵已由chkWf先行檢出(insert、insertBulk整批reject，save該筆ok為0)，不會到達本函數；錯誤訊息不回顯主鍵值
     *
     * @ignore
     * @param {Object} md 輸入資料表model物件
     * @param {Object} v 輸入數據物件
     * @param {Number} k 輸入數據於陣列內之索引
     * @param {String} mode 輸入呼叫之函數名稱字串
     * @returns {Object} 回傳{v,cannot}，v為補齊或正規化主鍵之數據物件
     */
    function procPk(md, v, k, mode) {

        //normPk
        let pkv = get(v, opt.pk)
        let r = normPk(pkv, getMdPkType(md))

        //check, 有效者寫回正規化值
        if (r.kind === 'ok') {
            v[opt.pk] = r.v
            return { v: lockPk(v), cannot: false }
        }

        //check, 型別不符
        if (r.kind === 'mismatch') {
            throw new Error(`invalid data[${k}].${opt.pk}, type mismatch with pk column [${opt.pk}] in model [${opt.cl}]`)
        }

        //check, 不可能存在
        if (r.kind === 'cannot') {
            if (mode === 'save') {
                return { v: lockPk(v), cannot: true }
            }
            throw new Error(`invalid data[${k}].${opt.pk}, can not be stored: exceeds 255 characters`)
        }

        //check, autoGenPk為false時主鍵須由呼叫端自備
        if (!opt.autoGenPk) {
            throw new Error(`invalid data[${k}].${opt.pk}, autoGenPk is false`)
        }

        //at
        let at = get(md, `rawAttributes.${opt.pk}`)
        if (!iseobj(at)) {
            throw new Error(`can not find pk column [${opt.pk}] in model [${opt.cl}]`)
        }

        //check, 自動產生之主鍵值為字串, 主鍵欄位須為字串類型方能容納
        let tp = get(at, 'type.key', '')
        if (!arrHas(tp, TPS_STR)) {
            throw new Error(`autoGenPk is true but pk column [${opt.pk}] in model [${opt.cl}] is [${tp}], auto generated pk is a string, need to set autoGenPk to false and supply pk by caller`)
        }

        //genIDSeq, 為UUIDv7格式而具單調遞增性, 主鍵接近順序遞增可減少索引頁面分裂
        v[opt.pk] = genIDSeq()

        return { v: lockPk(v), cannot: false }
    }


    /**
     * 初始化操作實例
     *
     * 註: connMDB.exe為one-shot程序，每次呼叫各自開啟與關閉連線，故實例本身不持有資料庫連線；
     * sequelize僅用於匯入models以取得欄位定義，不承載任何數據
     * 註: 每個實例自帶其sequelize(區域變數)，close只關閉自己的且可重複呼叫(第二次起為空操作)，
     * 故useStable為false之並行呼叫、重複init皆各自釋放，不會被後建者覆寫而漏關或被誤關；close之後不再使用該實例
     *
     * @memberOf WOrmMdb
     * @returns {Promise} 回傳Promise，resolve回傳實例物件{mds,jet,err,close}，reject回傳錯誤訊息
     */
    async function initAdodb() {
        let err = null

        //jet, 透過connMDB.exe操作, 使用Windows內建Jet 4.0引擎, 目標機不需安裝任何東西
        //查詢結果由exe逐列串流寫jsonl, 不受exe程序記憶體限制, 可支援至mdb格式上限(2GB)
        let jet = jetOpen({ path: opt.storage, password: getDbPassword() })

        //initSequelize, 匯入失敗屬影響本次操作全部數據之整批性錯誤
        let sequelize = null
        let mds = null
        await initSequelize(opt, logSql)
            .then((r) => {
                sequelize = r.sequelize
                mds = r.mds
            })
            .catch((e) => {
                err = getErrMsg(e)
            })

        //closed, 本實例是否已關閉
        let closed = false

        return {
            mds,
            jet,
            err,
            close: async() => {
                if (closed) {
                    return
                }
                closed = true
                if (sequelize !== null) {
                    await sequelize.close()
                }
            },
        }
    }


    /**

    /**
     * 解析查詢條件內各主鍵值所命中之列序號, 由Jet判定等值
     *
     * 註: 先以全表數據之主鍵存值之快速鍵(kFast, 只會少判)對應; 對不上者(全半形、假名、非ASCII大小寫、長字串等變體)
     * 於單次exe往返內逐筆以=語句交Jet判定, 取回之存值再對應回全表數據之序號
     * 註: 不以JS仿製之等值鍵判定: 近似鍵多判則select/delAll命中Jet視為相異之列, 少判則$ne/$nin把Jet視為同鍵之列當成相異而刪除
     *
     * @ignore
     * @param {Object} si 輸入實例物件
     * @param {Array} data 輸入全表數據
     * @param {Array} vals 輸入正規化後之主鍵值陣列
     * @returns {Promise} 回傳Promise，resolve回傳函數(主鍵值→命中列之序號陣列)
     */
    async function resolvePkIdx(si, data, vals) {

        //keyOf, 區分型別之精確鍵
        let keyOf = (v) => {
            return `${typeof v}:${String(v)}`
        }

        //mExact, mFast, 存值→序號
        let mExact = new Map()
        let mFast = new Map()
        each(data, (row, i) => {
            let s = get(row, opt.pk)
            if (s === null || s === undefined) {
                return
            }
            mExact.set(keyOf(s), i)
            mFast.set(kFast(s), i)
        })

        //res, 主鍵值→序號陣列
        let res = new Map()
        let unmatched = []
        each(vals, (v) => {
            let k = keyOf(v)
            if (res.has(k)) {
                return
            }
            let i = mFast.get(kFast(v))
            if (i !== undefined) {
                res.set(k, [i])
                return
            }
            res.set(k, [])
            unmatched.push(v)
        })

        //unmatched, 逐筆以=語句交Jet判定
        if (size(unmatched) > 0) {
            let r = await si.jet.run(map(unmatched, (v) => {
                return {
                    type: 'query',
                    sql: getSelectByPk(opt.cl, opt.pk, v),
                    stopOnError: false,
                }
            }))
            if (!r.ok) {
                throw new Error(r.error)
            }
            each(unmatched, (v, j) => {
                let is = []
                each(get(r, `results.${j}.rows`, []), (row) => {
                    let i = mExact.get(keyOf(get(row, opt.pk)))
                    if (i !== undefined) {
                        is.push(i)
                    }
                })
                res.set(keyOf(v), is)
            })
        }

        return (v) => {
            return res.get(keyOf(v)) || []
        }
    }


    /**
     * 由Jet取回全表數據後於記憶體內依條件過濾
     *
     * 註: Access之SQL方言不支援$in、$nin等條件，故不將條件送Jet而由記憶體過濾
     * 註: 主鍵之等值類條件由castPkFind改寫為命中列之序號(以resolvePkIdx由Jet判定)，故命中判定與selectByPk、insert、save、del一致；
     * 主鍵之範圍運算子仍於記憶體sqlite比對(近似)
     * 註: 其餘條件原樣交w-orm-reladb之cvFind轉譯(於queryMemory內)，不支援之運算子與無法轉譯之值reject(見CLAUDE_rulebook.md之R-FIND)
     * 註: find須為normFind回傳之複本(已依系列白名單檢核, 呼叫端不得傳入未經檢核之find)
     *
     * @ignore
     * @param {Object} si 輸入實例物件
     * @param {Object} find 輸入查詢條件物件，須為normFind回傳之複本
     * @returns {Promise} 回傳Promise，resolve回傳數據陣列(Jet原列)
     */
    async function findAll(si, find) {

        //md
        let md = getMd(si)
        let attrs = get(md, 'rawAttributes', {})
        let pkType = getMdPkType(md)

        //check, 條件引用model宣告為非白名單欄型(TIME、ENUM、JSON、BLOB等)之欄者一律拒收(R-FLOAT-07), 先於讀取全表與其後之任何寫入; select與delAll共用
        chkFindColKind(attrs, find)

        //data, 先查詢出access mdb內全部資料
        let data = await si.jet.query(getSelectAll(opt.cl))

        //keys, 記憶體過濾表之原列序號欄名稱, 附加亂數令其不與使用者之欄位或條件同名
        let keys = genInnerKeys(attrs)

        //findPk, 於複本上單趟走訪: 主鍵等值類條件改寫為序號佔位條件, 其餘條件原樣保留, 於queryMemory內交cvFind轉譯; $ne與$nin之無效主鍵值於此拋出
        //註: opt.pk非model之屬性時不辨識主鍵條件, 主鍵名之鍵交cvFind以嚴格鍵拒收(否則近似之主鍵名繞過嚴格鍵, run02外審opus)
        //註: opt.pk亦須為Jet列實有之欄(connMDB.exe每列輸出全部欄位故取首列, 無列時無從得知; 與queryMemory之過濾表同法)且名稱完全相符; model與資料表欄名大小寫不符(model有id而資料表為ID)時,
        //主鍵條件若仍改寫為序號條件, 因取不到存值而被化簡為[查無此主鍵]或[全部], 令select漏查而delAll拒收(外審sol F03); 不辨識者交cvFind以嚴格鍵拒收
        let pkKey = Object.prototype.hasOwnProperty.call(attrs, opt.pk) && (data.length === 0 || Object.prototype.hasOwnProperty.call(data[0] || {}, opt.pk)) ? opt.pk : null
        let { find: findPk, slots } = castPkFind(find, pkKey, pkType, keys.wi)

        //vals, 整個find內之主鍵值
        let vals = []
        for (let s of slots) {
            vals.push(...s.vals)
        }

        //check, 相異主鍵值之總數上限: normFind只限制單一$in/$nin陣列(MAX_IN), 而每個kFast對不上之值需由Jet逐筆判定(約1.6ms),
        //分散於$or/$and內之多個陣列可使總數遠超單一陣列上限(實測98000值阻塞同行程之全域佇列328秒; 外審opus F3), 故於送Jet前就總數把關
        let nPk = new Set(vals.map((v) => `${typeof v}:${String(v)}`)).size
        if (nPk > MAX_IN) {
            throw new Error(`invalid find: too many primary key values (> ${MAX_IN}) at [find]`)
        }

        //idxOf, 由Jet判定各主鍵值之命中列, 填入序號佔位
        let idxOf = await resolvePkIdx(si, data, vals)
        fillPkSlots(slots, idxOf)

        //queryMemory
        let rs = await queryMemory(opt, attrs, data, findPk, keys, logSql)

        return rs
    }


    /**
     * 查詢數據
     *
     * 使用須知:
     * 1. find未給、為undefined或為{}時回傳全部數據。
     * 2. 傳了值卻不是條件物件(null、陣列含[]與[{...}]、字串、數值、布林、函數、Date、RegExp、Map、Set、類別實例等)一律整批reject，不視為{}。
     * 3. 條件僅支援系列白名單: 欄位等值{欄:純量}(多欄為AND)、欄位運算子$eq $ne $gt $gte $lt $lte(值為純量)與
     *    $in $nin(值為純量陣列，各至多2000個元素)、文件層$and $or(值為條件物件之非空陣列，至多999項)。純量為字串、有限數字、布林、有效Date；
     *    null僅可用於欄位等值、$eq、$ne。白名單外之運算子($not $nor $regex $options $exists $where $expr $like $ilike等)、
     *    欄位層$and/$or、子查詢、函數值、Symbol鍵、undefined值、空的$nin/$and/$or、白名單外之欄名(須為model之屬性且符合^[\p{L}_][\p{L}\p{M}\p{N}_]*$)等
     *    一律整批reject，訊息為invalid find: 原因 at [路徑]。
     * 4. 值依欄位型別檢核，DATE欄之日期條件為浮動時間(牆上時間，見6.)；主鍵等值類條件由Jet判定命中，與selectByPk、del一致(見CLAUDE_rulebook.md之R-WL、R-FIND、R-PK)；
     *    整個find內相異主鍵值總數亦至多2000(跨陣列合計)；主鍵之$ne:null與其他欄位相同，意為[非NULL](主鍵不會是NULL，故命中全部列)，可攜寫法亦可用於主鍵欄；
     *    主鍵之範圍運算子($gt $gte $lt $lte)與其他欄位相同依欄位型別比較: 界限為整數主鍵之2.5、或超過255字元之字串亦正確比較，與欄位型別不符者(如整數主鍵給'abc'、布林)reject。
     * 5. 語意差異(SQL式): $ne/$nin不命中NULL(三值邏輯)；字串比對不分大小寫(Jet)。需明確表達時可用可攜寫法:
     *    排除NULL為{$and:[{f:{$ne:null}},{f:{$ne:x}}]}，含NULL為{$or:[{f:null},{f:{$ne:x}}]}。
     * 6. DATE欄之日期條件以牆上時間(浮動時間)比較，與主機時區及夏令無關(Jet之DATETIME為無時區牆上時間)：無時區字串(yyyy-MM-ddTHH:mm:ss，T或單一空白分隔)直接取其牆上分量；
     *    Date、epoch與帶時區之ISO字串先得瞬間，再取其於主機時區之本地分量(new Date(2026,0,1)即2026-01-01 00:00:00)；純日期字串reject。
     *    負偏移時區主機(如America/Los_Angeles)含9999-12-31 23:59:59之[永不過期]哨兵列時，範圍條件與delAll亦正確(原已知限制LF8、LF4，第87項B4已解)。
     *    Jet回傳之DATE欄值於過濾前一律換算為同一浮動空間，無法換算者(如model宣告DATE而資料表欄實為任意文字)整批reject，訊息invalid data: date can not be converted to floating time at [row[索引].欄位名](不回顯值)；含不帶條件之select()亦然(全表與帶條件走同一路徑)，不帶條件之delAll()走DELETE FROM不經記憶體過濾故不受影響；條件值本身不合法者由cvFind先行拒收(invalid find)，先於資料列換算。
     * 7. 條件只可引用model宣告為Jet可對應欄型之欄: STRING、TEXT、CHAR、CITEXT、UUID(文字)，INTEGER、BIGINT、SMALLINT、MEDIUMINT、TINYINT(整數)，FLOAT、REAL、DOUBLE、DECIMAL、NUMBER(數值)，DATE、DATEONLY(日期時間)，BOOLEAN(是否)。
     *    引用其他欄型(TIME、ENUM、JSON、JSONB、BLOB、UUIDV1、UUIDV4、NOW、ARRAY、RANGE、GEOMETRY、GEOGRAPHY、HSTORE、INET、CIDR、MACADDR、TSVECTOR)之欄(任何運算子與值形式、含null、含巢狀$and/$or、屬性名或資料庫欄名皆算)者一律整批reject，
     *    訊息invalid find: column type <型別> is not supported at [find.欄名]，先於讀取全表與任何刪除，不回顯值(R-FLOAT-07)。Jet欄型沒有這些型別(TIME更無[僅時間]型別)，宣告必為誤宣告，記憶體過濾將以與Jet不同之方式比較(如文字欄分大小寫、日期時間欄依文字比較，delAll會多刪)；
     *    請把Jet之文字欄宣告為STRING/TEXT、整數欄INTEGER、浮點欄DOUBLE、DATETIME欄DATE(或DATEONLY)、是否欄BOOLEAN。不引用該欄者(含select()與delAll())不受影響。
     *
     * 註: 恆回傳陣列，無符合數據回傳空陣列而不回傳null
     * 註: 條件之入口形狀檢核(白名單、純量型別、欄名文法、上限、異常結構)先於載入model、讀取與連線，未通過者不開啟資料庫檔、不送SQL，並以整批性錯誤reject(發出一次error事件，不發change事件)；
     * 通過形狀檢核但欄位名不在model或資料表、值與欄位型別不符者，於載入model並讀取全表之後才由轉譯層reject
     * 註: 本函數不得有副作用，故不創建資料表
     *
     * @memberOf WOrmMdb
     * @param {Object} [find={}] 輸入查詢條件物件(系列白名單，規則見上)，未給、undefined或{}回傳全部數據，非條件物件或白名單外運算子整批reject
     * @param {Object} [option={}] 輸入設定物件，預設為{}
     * @param {Object} [option.instance=null] 輸入實例instance物件，預設為null
     * @returns {Promise} 回傳Promise，resolve回傳數據陣列，reject回傳錯誤訊息
     */
    async function select(find = {}, option = {}) {

        //instance
        let instance = get(option, 'instance', null)

        //isErr, res
        let isErr = false
        let res = null

        //si, inited為本次是否自行初始化(壞find不初始化, 故不得關閉他次呼叫所建之sequelize)
        let si = instance
        let inited = false

        try {

            //check, 條件之入口檢核為第一步, 先於初始化(匯入model)與讀取, 其後只用複本(R-WL-01)
            let fd = normFind(find)

            //initAdodb
            if (instance === null) {
                inited = true
                si = await initAdodb()
            }

            //check, 連線或匯入models失敗影響本次操作之全部數據, 屬整批性錯誤
            if (si.err) {
                throw si.err
            }

            //findAll, 恆回傳陣列, 無符合數據為空陣列
            res = await findAll(si, fd)
            if (!isarr(res)) {
                res = []
            }

        }
        catch (err) {
            isErr = true
            res = err
        }
        finally {

            //close, 關閉本次自行建立之實例(各實例自帶sequelize, 見R-LIFE)
            if (inited && si !== null) { //內部自動初始化得close(si為null代表初始化未完成, 無從關閉)
                await si.close()
            }

        }

        //check
        if (isErr) {
            emitError('select', null, res)
            return Promise.reject(res)
        }

        return res
    }


    /**
     * 由主鍵查詢單筆數據，因由Jet依主鍵取值且僅回傳單筆，不需如select提取全部數據再過濾，故數據量大時效能較佳
     *
     * 註: 主鍵欄位取自opt.pk，預設為id，支援由呼叫端指定
     * 註: 主鍵未命中、主鍵值無效(未給、型別不符)或不可能存在(字串類主鍵超過255字元、含NUL或孤立代理)皆回傳null而不reject，
     * 含NUL或孤立代理者先於初始化即回傳null(不載入model、不送Jet，亦不命中U+FFFD之鄰近列)，
     * [命中]以Jet之判定為準，與insert、save、del一致
     * 註: Jet之字串等值不分大小寫、忽略尾端半形空白與全半形寬度等，故主鍵之命中判定亦同(見類別註解)
     * 註: 本函數不得有副作用，故不創建資料表
     *
     * @memberOf WOrmMdb
     * @param {String|Number} pk 輸入主鍵值，即數據內opt.pk欄位之值，字串類主鍵欄之有限數字以String(v)處置，數值類主鍵欄之標準數字字串轉為數字
     * @param {Object} [option={}] 輸入設定物件，預設為{}
     * @param {Object} [option.instance=null] 輸入實例instance物件，預設為null
     * @returns {Promise} 回傳Promise，resolve回傳數據物件，若無此主鍵或主鍵值無效則回傳null，reject回傳錯誤訊息
     */
    async function selectByPk(pk, option = {}) {

        //check, 與型別無關之無效值(未給、空字串、NaN、±Infinity、非字串非數字)與不良構字串(含NUL或孤立代理, 帶why)視為查無數據, 不需初始化,
        //亦不送查詢以免無效值被轉為null而誤中其他數據, 或孤立代理經UTF-8轉換被改寫為U+FFFD而命中他筆
        let r0 = normPk(pk, 'other')
        if (r0.kind === 'invalid' || r0.why !== undefined) {
            return null
        }

        //instance
        let instance = get(option, 'instance', null)

        //isErr, res
        let isErr = false
        let res = null

        //si
        let si = instance
        if (instance === null) {
            si = await initAdodb()
        }

        try {

            //check
            if (si.err) {
                throw si.err
            }

            //normPk, 依主鍵欄型別正規化, 型別不符或不可能存在者視為查無而不送Jet
            let r = normPk(pk, getMdPkType(getMd(si)))
            if (r.kind === 'ok') {

                //query
                let rs = await si.jet.query(getSelectByPk(opt.cl, opt.pk, r.v))

                //check, 判定基準與insert、save、del內對既有數據之認定一致
                let v = get(rs, 0, null)
                if (iseobj(v)) {
                    res = v
                }
                else {
                    //不存在主鍵, 回傳null
                    res = null
                }

            }
            else {
                res = null
            }

        }
        catch (err) {
            isErr = true
            res = err
        }
        finally {

            //close, 關閉本次自行建立之實例(各實例自帶sequelize, 見R-LIFE)
            if (instance === null) { //內部自動初始化得close
                await si.close()
            }

        }

        //check
        if (isErr) {
            emitError('selectByPk', null, res)
            return Promise.reject(res)
        }

        return res
    }


    /**
     * 核對指定之主鍵是否確實存在於資料表
     *
     * 註: Jet之重複鍵錯誤碼3022涵蓋主鍵與其他唯一索引之衝突，兩者無從由錯誤碼區辨，
     * 故須另行核對；若該主鍵並不存在，即表示係撞及其他唯一索引，屬影響該筆以外之錯誤而不得視為[已存在則跳過]
     * 註: 先以批次IN取回存值並以快速鍵(kFast)對應，對不上者再逐筆以=語句交Jet判定(getExistPksExact)，
     * 因快速鍵只涵蓋尾端空白與ASCII大小寫，且Jet對長字串之IN與=不等價(已實測255個é之主鍵IN不中而=命中)
     *
     * @ignore
     * @param {Object} si 輸入實例物件
     * @param {Array} pkvs 輸入主鍵值陣列
     * @returns {Promise} 回傳Promise，resolve回傳已存在主鍵之快速鍵Set
     */
    async function getExistPks(si, pkvs) {

        //hs
        let hs = new Set()

        //check
        if (size(pkvs) === 0) {
            return hs
        }

        //cmds, 分批以免IN清單過長
        let cmds = map(chunk(pkvs, nPkPerIn), (vs) => {
            return {
                type: 'query',
                sql: getSelectByPks(opt.cl, opt.pk, vs),
            }
        })

        //run
        let r = await si.jet.run(cmds)
        if (!r.ok) {
            throw new Error(r.error)
        }

        //collect
        each(r.results, (rr) => {
            each(get(rr, 'rows', []), (v) => {
                hs.add(kFast(get(v, opt.pk)))
            })
        })

        return hs
    }


    /**
     * 逐筆以=語句核對主鍵是否確實存在於資料表，由Jet判定等值
     *
     * 註: 供快速鍵對應不到者使用(如全半形、平片假名、非ASCII大小寫之變體，或IN失效之長字串)，
     * 各筆於單次exe往返內送出; 每筆query各寫一個jsonl，成本約2ms，故不作為常態路徑
     *
     * @ignore
     * @param {Object} si 輸入實例物件
     * @param {Array} pkvs 輸入主鍵值陣列
     * @returns {Promise} 回傳Promise，resolve回傳與pkvs等長之是否存在布林陣列
     */
    async function getExistPksExact(si, pkvs) {

        //check
        if (size(pkvs) === 0) {
            return []
        }

        //run
        let r = await si.jet.run(map(pkvs, (v) => {
            return {
                type: 'query',
                sql: getSelectByPk(opt.cl, opt.pk, v),
                stopOnError: false,
            }
        }))

        //check, 任一筆查詢失敗即無從判定, 屬整批性錯誤
        if (!r.ok) {
            throw new Error(r.error)
        }

        return map(pkvs, (v, k) => {
            return size(get(r, `results.${k}.rows`, [])) > 0
        })
    }


    /**
     * 插入數據，僅於主鍵不存在時寫入，已存在者跳過且不覆寫
     *
     * 由Jet於主鍵之唯一約束上原子完成[檢查主鍵不存在]與[寫入]，併發時同一主鍵僅有一次成功
     *
     * 註: n為輸入筆數即本次嘗試插入之基準，nInserted為實際插入筆數，全數已存在而nInserted為0屬正常結果
     * 註: 同批含重複主鍵時僅首筆計入nInserted，其餘視為已存在；重複之判定以Jet為準(含大小寫、尾端空白、全半形等變體)
     * 註: opt.autoGenPk為true(預設)時未帶有效主鍵者自動產生，為false時未帶有效主鍵即reject且同批皆不寫入
     * 註: 主鍵值依主鍵欄型別正規化(見類別註解)；型別不符或不可能存在之主鍵於任何寫入之前整批reject
     * 註: 字串良構檢核(見類別註解)：主鍵含NUL或孤立代理、資料之鍵名與字串值含孤立代理者，於初始化(匯入model)之前即整批reject，不寫任何一筆，
     * 訊息為invalid id: 原因 at [data[索引].主鍵欄]或invalid data: 原因 at [路徑](不回顯值)，不隨opt.autoGenPk改變(孤立代理主鍵不會被自動產生之主鍵取代)
     * 註: 撞鍵者之核對以Jet為準：先以快速鍵對應，對不上者逐筆以=語句查詢，仍不存在即撞及其他唯一索引而整批reject
     * 註: 全部插入語句於單次呼叫exe內循序送出且不因單筆衝突而中止，故一次往返即可取得精確之nInserted
     * 註: option.returnList為true時改回傳與輸入等長且保序之逐筆陣列[{n,nInserted,ok}]，
     * 供呼叫端得知[是哪幾筆]為新資料而非僅[有幾筆]；逐筆元素之n與ok恆為1，
     * 因insert之任何錯誤皆屬整批性錯誤而reject，故不出現ok為0與err。
     * 回傳形式之切換為靜態，僅由本選項之取值決定，不因數據內容或執行結果而變
     *
     * @memberOf WOrmMdb
     * @param {Object|Array} data 輸入數據物件或陣列
     * @param {Object} [option={}] 輸入設定物件，預設為{}
     * @param {Object} [option.instance=null] 輸入實例instance物件，預設為null
     * @param {Boolean} [option.returnList=false] 輸入是否改回傳與輸入等長之逐筆結果陣列，預設為false
     * @returns {Promise} 回傳Promise，resolve回傳插入結果{n,nInserted,ok}，或於option.returnList為true時回傳[{n,nInserted,ok}]，reject回傳錯誤訊息
     */
    async function insert(data, option = {}) {

        //returnList
        let returnList = get(option, 'returnList', false) === true

        //check
        if (!iseobj(data) && !isearr(data)) {
            if (returnList) {
                return []
            }
            return {
                n: 0,
                nInserted: 0,
                ok: 1,
            }
        }

        //instance
        let instance = get(option, 'instance', null)

        //data為呼叫當下之快照(見snap), 其後檢核與寫入皆只使用此份
        if (!isarr(data)) {
            data = [data]
        }

        //chkWf, 主鍵(含NUL或孤立代理)與資料(孤立代理)之良構預檢, 須先於初始化(匯入model)與任何寫入, 任一筆不合格即整批reject, 以索引最小者為準
        let msg = null
        try {
            msg = firstWf(chkWf(data, true))
        }
        catch (err) {
            emitError('insert', data, err)
            return Promise.reject(err)
        }
        if (msg !== null) {
            let err = new Error(msg)
            emitError('insert', data, err)
            return Promise.reject(err)
        }

        //isErr, res
        let isErr = false
        let res = null

        //si
        let si = instance
        if (instance === null) {
            si = await initAdodb()
        }

        try {

            //check
            if (si.err) {
                throw si.err
            }

            //md, cols
            let md = getMd(si)
            let cols = getCols(md)

            //procPk, 須於任何寫入之前一次完成, 令autoGenPk為false、主鍵型別不符或不可能存在而拋錯時同批之有效筆數亦不會被寫入
            data = map(data, (v, k) => {
                return procPk(md, v, k, 'insert').v
            })

            //chkDates, 日期值之整批預檢與正規化, 同樣須於任何寫入之前一次完成(R-DATE-02)
            chkDates(md, cols, data)

            //nAll, n之基準為輸入筆數
            let nAll = size(data)

            //cmds, stopOnError為false令單筆撞鍵不中止其餘筆數, 一次往返即完成整批
            let cmds = map(data, (v) => {
                return {
                    type: 'execute',
                    sql: getInsert(opt.cl, cols, v),
                    stopOnError: false,
                }
            })

            //run
            let r = await si.jet.run(cmds)

            //bInss, 逐筆是否已插入, 與輸入等長且保序
            //dups, 重複鍵者, 待核對係主鍵已存在或撞及其他唯一索引
            let bInss = map(data, () => {
                return false
            })
            let dups = []
            each(r.results, (rr, k) => {
                if (rr.ok) {
                    bInss[k] = true
                    return
                }
                if (rr.errorCode === CODE_DUP_KEY) {
                    dups.push({ k, rr })
                    return
                }
                //其餘錯誤影響本次操作之數據而非僅該筆, 屬整批性錯誤
                throw new Error(rr.error)
            })

            //check, 核對重複鍵者是否確為主鍵已存在
            if (size(dups) > 0) {
                let pkvs = map(dups, (v) => {
                    return get(data, `${v.k}.${opt.pk}`)
                })
                let hs = await getExistPks(si, pkvs)

                //unmatched, 快速鍵對應不到者, 逐筆以=語句交Jet判定
                let unmatched = dups.filter((v) => {
                    return !hs.has(kFast(get(data, `${v.k}.${opt.pk}`)))
                })
                let bs = await getExistPksExact(si, map(unmatched, (v) => {
                    return get(data, `${v.k}.${opt.pk}`)
                }))
                each(unmatched, (v, j) => {
                    if (!bs[j]) {
                        //主鍵並不存在, 即撞及其他唯一索引, 不得靜默跳過
                        throw new Error(v.rr.error)
                    }
                })
            }

            //res, 全數已存在而nInserted為0屬正常結果, 不視為錯誤
            if (returnList) {
                //逐筆結果, 逐筆元素之n與ok恆為1, 資訊由nInserted承載
                res = map(bInss, (b) => {
                    return {
                        n: 1,
                        nInserted: b ? 1 : 0,
                        ok: 1,
                    }
                })
            }
            else {
                res = {
                    n: nAll,
                    nInserted: size(bInss.filter((b) => {
                        return b
                    })),
                    ok: 1,
                }
            }

        }
        catch (err) {
            isErr = true
            res = err
        }
        finally {

            //close, 關閉本次自行建立之實例(各實例自帶sequelize, 見R-LIFE)
            if (instance === null) { //內部自動初始化得close
                await si.close()
            }

        }

        //check
        if (isErr) {
            emitError('insert', data, res)
            return Promise.reject(res)
        }

        //emit, 須於結果定案後發出
        emitChange('insert', data, res)

        return res
    }


    /**
     * 批次插入數據，全批視為一個單位：全部插入成功，或一筆都不寫入
     *
     * 本函數非insert之加速版，兩者衝突政策不同：insert於主鍵已存在時跳過該筆且整批ok為1，
     * 本函數則整批reject且不寫入任何一筆，同批含重複主鍵者亦視為衝突。
     * 確無衝突時兩者之可觀察結果完全相同，差異僅於有衝突時顯現。
     *
     * 註: n為輸入筆數即本次嘗試插入之基準；nInserted於成功時恆等於n，雖無額外資訊仍保留，
     * 令呼叫端得與insert共用同一段結果處理程式碼
     * 註: 不提供逐筆結果，故不出現ok為0與err；需要逐筆處置者改用insert
     * 註: opt.autoGenPk為true(預設)時未帶有效主鍵者自動產生，為false時未帶有效主鍵即reject且同批皆不寫入
     * 註: 主鍵值依主鍵欄型別正規化(見類別註解)；型別不符或不可能存在之主鍵於任何寫入之前整批reject
     * 註: 字串良構檢核(見類別註解)：主鍵含NUL或孤立代理、資料之鍵名與字串值含孤立代理者，於初始化(匯入model)之前即整批reject，不寫任何一筆，
     * 訊息為invalid id: 原因 at [data[索引].主鍵欄]或invalid data: 原因 at [路徑](不回顯值)，不隨opt.autoGenPk改變
     * 註: [全有全無]以Jet之交易(OleDbTransaction)包覆全部插入語句達成，任一筆失敗即回滾，
     * 故reject之後資料庫狀態與呼叫前相同，無須補償動作；同批含重複主鍵者亦於交易內被偵測為衝突
     *
     * @memberOf WOrmMdb
     * @param {Object|Array} data 輸入數據物件或陣列
     * @param {Object} [option={}] 輸入設定物件，預設為{}
     * @param {Object} [option.instance=null] 輸入實例instance物件，預設為null
     * @returns {Promise} 回傳Promise，resolve回傳插入結果{n,nInserted,ok}，reject回傳錯誤訊息
     */
    async function insertBulk(data, option = {}) {

        //check
        if (!iseobj(data) && !isearr(data)) {
            return {
                n: 0,
                nInserted: 0,
                ok: 1,
            }
        }

        //instance
        let instance = get(option, 'instance', null)

        //data為呼叫當下之快照(見snap), 其後檢核與寫入皆只使用此份
        if (!isarr(data)) {
            data = [data]
        }

        //chkWf, 主鍵(含NUL或孤立代理)與資料(孤立代理)之良構預檢, 須先於初始化(匯入model)與任何寫入, 任一筆不合格即整批reject, 以索引最小者為準
        let msg = null
        try {
            msg = firstWf(chkWf(data, true))
        }
        catch (err) {
            emitError('insertBulk', data, err)
            return Promise.reject(err)
        }
        if (msg !== null) {
            let err = new Error(msg)
            emitError('insertBulk', data, err)
            return Promise.reject(err)
        }

        //isErr, res
        let isErr = false
        let res = null

        //si
        let si = instance
        if (instance === null) {
            si = await initAdodb()
        }

        try {

            //check
            if (si.err) {
                throw si.err
            }

            //md, cols
            let md = getMd(si)
            let cols = getCols(md)

            //procPk, 須於任何寫入之前一次完成, 令autoGenPk為false、主鍵型別不符或不可能存在而拋錯時同批皆不會被寫入
            data = map(data, (v, k) => {
                return procPk(md, v, k, 'insertBulk').v
            })

            //chkDates, 日期值之整批預檢與正規化, 同樣須於任何寫入之前一次完成(R-DATE-02)
            chkDates(md, cols, data)

            //nAll, n之基準為輸入筆數
            let nAll = size(data)

            //cmds, 未加任何跳過選項, 故任一筆撞鍵即整批失敗, 同批重複主鍵亦於此被偵測為衝突
            let cmds = map(data, (v) => {
                return {
                    type: 'execute',
                    sql: getInsert(opt.cl, cols, v),
                }
            })

            //run, 以交易包覆令失敗時回滾而不寫入任何一筆
            let r = await si.jet.run(cmds, { useTransaction: true })

            //check
            if (!r.ok) {
                throw new Error(r.error)
            }

            //res, 全有全無故成功時nInserted恆等於n
            res = {
                n: nAll,
                nInserted: nAll,
                ok: 1,
            }

        }
        catch (err) {
            isErr = true
            res = err
        }
        finally {

            //close, 關閉本次自行建立之實例(各實例自帶sequelize, 見R-LIFE)
            if (instance === null) { //內部自動初始化得close
                await si.close()
            }

        }

        //check
        if (isErr) {
            emitError('insertBulk', data, res)
            return Promise.reject(res)
        }

        //emit, 須於結果定案後發出
        emitChange('insertBulk', data, res)

        return res
    }


    /**
     * 儲存數據，以主鍵為準更新既有數據，未給之欄位保留；主鍵不存在且option.autoInsert為true(預設)時改為插入
     *
     * 採條件寫入配合衝突偵測與重試: 每次寫入本身為單一條件式原子語句——插入由主鍵之唯一約束判定、
     * 更新由WHERE主鍵之比對判定，皆非由預讀值決定其成敗；預讀僅用於選擇發出哪一條語句，
     * 選錯不會產生錯誤結果，只會被偵測並重試(插入撞既有主鍵、更新未命中任何列)，故縱使預讀值已過期，
     * 最終結果仍與該次操作單獨執行時相同。
     *
     * 註: 回傳陣列恆與輸入等長，輸入單一物件亦回傳長度1之陣列
     * 註: n為主鍵命中筆數，值為0或1，命中(不論內容有無變更)或經插入而產生皆為1；nInserted與nModified恆同時出現
     * 註: [內容相同]之判定基準為將待寫入物件合併進現值後與現值相同，非待寫入物件與現值全等，
     * 故只給部份欄位且該些欄位值皆與現值相同時，合併結果等於現值，nModified為0。
     * 合併取淺層以與Jet整欄取代之寫入行為一致，令nModified忠實反映資料庫端是否真的寫入
     * 註: 不以UPDATE之影響列數決定nModified，因Jet之影響列數為[符合WHERE之列數]而非[內容真的有變之列數]
     * (已實測: 將欄位設為與現值相同之值仍回報影響1列)
     * 註: 本筆失敗不中斷整批，該筆以ok為0並附err回報
     * 註: opt.autoGenPk為true(預設)時未帶有效主鍵者自動產生，為false時未帶有效主鍵即reject且同批皆不寫入
     * 註: 主鍵值依主鍵欄型別正規化(見類別註解)；型別不符者於任何寫入之前整批reject(比照w-orm-postgresql)；
     * 不可能存在之主鍵(字串類主鍵超過255字元)視為不存在且不送Jet，
     * autoInsert為true時因無法寫入而該筆ok為0並附err，為false時n為0
     * 註: 字串良構檢核(見類別註解)：主鍵含NUL或孤立代理、資料之鍵名與字串值含孤立代理者，該筆ok為0並附err(autoInsert為false者亦然，原為靜默n為0)，
     * 同批其餘筆照常處理，不連線亦不進入其後之主鍵正規化與日期預檢；err為invalid id: 原因 at [data[索引].主鍵欄]或invalid data: 原因 at [路徑](不回顯值)，
     * 該類檢核先於初始化(匯入model)，故全數不合格時不載入model、不開啟資料庫檔
     * 註: 各回合之預讀與寫入皆整批送出，故N筆數據於無衝突時僅需2次呼叫exe而非2N次
     *
     * @memberOf WOrmMdb
     * @param {Object|Array} data 輸入數據物件或陣列
     * @param {Object} [option={}] 輸入設定物件，預設為{}
     * @param {Object} [option.instance=null] 輸入實例instance物件，預設為null
     * @param {Boolean} [option.autoInsert=true] 輸入是否於儲存時發現原本無數據，則自動改以插入處理，預設為true
     * @returns {Promise} 回傳Promise，resolve回傳與輸入等長之儲存結果陣列[{n,nInserted,nModified,ok}]，reject回傳錯誤訊息
     */
    async function save(data, option = {}) {

        //check
        if (!iseobj(data) && !isearr(data)) {
            return []
        }

        //instance
        let instance = get(option, 'instance', null)

        //autoInsert
        let autoInsert = get(option, 'autoInsert', true)

        //nTry, 預測錯誤時重試, 給予有限次數令其收斂
        let nTry = 3

        //isErr, res
        let isErr = false
        let res = null

        //inserteds, 供結果定案後發出insert事件用
        let inserteds = []

        //data為呼叫當下之快照(見snap), 其後檢核與寫入皆只使用此份
        if (!isarr(data)) {
            data = [data]
        }

        //chkWf, 主鍵(含NUL或孤立代理)與資料(孤立代理)之良構預檢, 須先於初始化(匯入model)、讀取與寫入;
        //不合格者(含autoInsert為false者)該筆ok為0並附err, 不中斷同批其餘筆, 亦不進入其後之procPk、chkDates與寫入
        let msgs = null
        try {
            msgs = chkWf(data, true)
        }
        catch (err) {
            emitError('save', data, err)
            return Promise.reject(err)
        }

        //rests, 逐筆結果, 未定案者為null
        let rests = map(msgs, (m) => {
            if (m === null) {
                return null
            }
            return {
                n: 1,
                nInserted: 0,
                nModified: 0,
                ok: 0,
                err: m,
            }
        })

        //nPend, 預檢後尚待處理之筆數, 為0則無需初始化與連線
        let nPend = size(rests.filter((v) => {
            return v === null
        }))

        //si
        let si = instance
        if (instance === null && nPend > 0) {
            si = await initAdodb()
        }

        try {

            //check, 全數於預檢即已定案
            if (nPend > 0) {

                //check
                if (si.err) {
                    throw si.err
                }

                //md, cols
                let md = getMd(si)
                let cols = getCols(md)

                //procPk, 須於任何寫入之前一次完成, 令autoGenPk為false或主鍵型別不符而拋錯時同批之有效筆數亦不會被寫入; 預檢不合格者略過
                let cannots = []
                data = map(data, (v, k) => {
                    if (rests[k] !== null) {
                        return v
                    }
                    let r = procPk(md, v, k, 'save')
                    if (r.cannot) {
                        cannots.push(k)
                    }
                    return r.v
                })

                //chkDates, 日期值之整批預檢與正規化, 含autoInsert為false與不會寫入者, 越界即整批reject而不降為該筆ok為0(R-DATE-02); 預檢不合格者以null占位(索引不變)略過
                chkDates(md, cols, map(data, (v, k) => {
                    return rests[k] === null ? v : null
                }))

                //check, 不可能存在之主鍵視為不存在且不送Jet: autoInsert為true時因無法寫入而該筆失敗, 為false時為未命中
                each(cannots, (k) => {
                    if (autoInsert) {
                        rests[k] = {
                            n: 1,
                            nInserted: 0,
                            nModified: 0,
                            ok: 0,
                            err: `can not save data[${k}].${opt.pk}, ${opt.pk} exceeds 255 characters`,
                        }
                    }
                    else {
                        rests[k] = {
                            n: 0,
                            nInserted: 0,
                            nModified: 0,
                            ok: 1,
                        }
                    }
                })

                //pends, 待處理之索引
                let pends = []
                each(rests, (v, k) => {
                    if (v === null) {
                        pends.push(k)
                    }
                })

                for (let iTry = 0; iTry < nTry && size(pends) > 0; iTry++) {

                    //預讀, 供判斷內容是否相同之快速路徑, 其結果不用於決定寫入內容
                    let cmdsRead = map(pends, (i) => {
                        return {
                            type: 'query',
                            sql: getSelectByPk(opt.cl, opt.pk, get(data, `${i}.${opt.pk}`)),
                            stopOnError: false,
                        }
                    })
                    let rRead = await si.jet.run(cmdsRead)

                    //check, 連線開啟重試耗盡影響本次操作之全部數據, 屬整批性錯誤而非逐筆失敗(T4)
                    if (rRead.openFailed === true) {
                        throw new Error(rRead.error)
                    }

                    //writes, 由預讀結果選擇發出哪一條語句
                    let writes = []
                    each(pends, (i, j) => {
                        let v = data[i]
                        let rr = get(rRead, `results.${j}`, null)

                        //check, 預讀失敗視為本筆失敗, 不中斷整批
                        if (!rr || !rr.ok) {
                            rests[i] = {
                                n: 1,
                                nInserted: 0,
                                nModified: 0,
                                ok: 0,
                                err: getErrMsg(get(rr, 'error', 'can not read data')),
                            }
                            return
                        }

                        //_v, 現值
                        let _v = get(rr, 'rows.0', null)

                        if (iseobj(_v)) {
                            //主鍵存在

                            //_vt, vt, 以待寫入物件之非主鍵欄位淺層覆蓋現值後與現值比對
                            let _vt = omit(_v, opt.pk)
                            let vt = {
                                ..._vt,
                                ...pick(omit(v, opt.pk), cols),
                            }

                            //check, 內容相同者不寫入
                            if (isEqual(vt, _vt)) {
                                rests[i] = {
                                    n: 1,
                                    nInserted: 0,
                                    nModified: 0,
                                    ok: 1,
                                }
                                return
                            }

                            //sql, 單一UPDATE語句由WHERE主鍵原子完成查找與更新
                            let sql = getUpdate(opt.cl, cols, v, opt.pk, get(v, opt.pk))
                            if (sql === null) {
                                //無可更新之欄位, 等同未寫入
                                rests[i] = {
                                    n: 1,
                                    nInserted: 0,
                                    nModified: 0,
                                    ok: 1,
                                }
                                return
                            }

                            writes.push({ i, kind: 'update', sql })
                            return
                        }

                        //主鍵不存在且未開啟autoInsert則不寫入以免無中生有
                        if (!autoInsert) {
                            rests[i] = {
                                n: 0,
                                nInserted: 0,
                                nModified: 0,
                                ok: 1,
                            }
                            return
                        }

                        //sql, 單一INSERT語句由主鍵之唯一約束原子完成檢查與寫入
                        writes.push({
                            i,
                            kind: 'insert',
                            sql: getInsert(opt.cl, cols, v),
                        })
                    })

                    //run, 各寫入彼此獨立故不中止
                    if (size(writes) > 0) {
                        let rWrite = await si.jet.run(map(writes, (w) => {
                            return {
                                type: 'execute',
                                sql: w.sql,
                                stopOnError: false,
                            }
                        }))

                        //check, 連線開啟重試耗盡影響本次操作之全部數據, 屬整批性錯誤而非逐筆失敗(T4)
                        if (rWrite.openFailed === true) {
                            throw new Error(rWrite.error)
                        }

                        each(writes, (w, j) => {
                            let rr = get(rWrite, `results.${j}`, null)

                            //check
                            if (!rr) {
                                rests[w.i] = {
                                    n: 1,
                                    nInserted: 0,
                                    nModified: 0,
                                    ok: 0,
                                    err: 'can not get result of writing',
                                }
                                return
                            }

                            if (rr.ok) {
                                if (w.kind === 'update') {
                                    if (get(rr, 'n', 0) > 0) {
                                        rests[w.i] = {
                                            n: 1,
                                            nInserted: 0,
                                            nModified: 1,
                                            ok: 1,
                                        }
                                        return
                                    }
                                    //該列已被他方刪除, 留待重試改走插入
                                    return
                                }
                                rests[w.i] = {
                                    n: 1,
                                    nInserted: 1,
                                    nModified: 0,
                                    ok: 1,
                                }
                                inserteds.push(w.i)
                                return
                            }

                            //check, 他方已插入同一主鍵, 留待重試改走更新
                            if (w.kind === 'insert' && rr.errorCode === CODE_DUP_KEY) {
                                return
                            }

                            //其餘錯誤視為本筆失敗, 不中斷整批, 由呼叫端以ok與err判讀
                            rests[w.i] = {
                                n: 1,
                                nInserted: 0,
                                nModified: 0,
                                ok: 0,
                                err: getErrMsg(rr.error),
                            }
                        })
                    }

                    //pends, 取仍未定案者
                    pends = []
                    each(rests, (v, k) => {
                        if (v === null) {
                            pends.push(k)
                        }
                    })
                }

                //check, 重試耗盡仍未定案
                each(pends, (i) => {
                    rests[i] = {
                        n: 1,
                        nInserted: 0,
                        nModified: 0,
                        ok: 0,
                        err: `can not save data[${i}].${opt.pk} in ${nTry} tries`,
                    }
                })

            }

            //res
            res = rests

        }
        catch (err) {
            isErr = true
            res = err
        }
        finally {

            //close, 關閉本次自行建立之實例(各實例自帶sequelize, 見R-LIFE)
            if (instance === null && si !== null) { //內部自動初始化得close
                await si.close()
            }

        }

        //check
        if (isErr) {
            emitError('save', data, res)
            return Promise.reject(res)
        }

        //emit, 逐筆事件於各筆結果定案後依輸入順序發出, 且早於整批change
        each(res, (v, k) => {
            if (arrHas(k, inserteds)) {
                emitChange('insert', [data[k]], v)
            }
            if (v.ok === 0) {
                emitError('save', [data[k]], v.err)
            }
        })

        //emit, 須於結果定案後發出
        emitChange('save', data, res)

        return res
    }


    /**
     * 刪除數據
     *
     * 註: 回傳陣列恆與輸入等長，各筆之n與nDeleted皆為主鍵命中筆數，值為0或1，未命中為0且屬正常結果
     * 註: 判斷某筆是否真的被刪除一律以nDeleted為準
     * 註: 未帶有效主鍵者為該筆之輸入問題，回ok為0與err且不送查詢條件(以免無效值被轉為null而誤中其他數據)，
     * 不中斷其餘筆數，以此與[主鍵未命中]之ok為1區辨
     * 註: 主鍵值依主鍵欄型別正規化(見類別註解)；型別不符者該筆ok為0並附err；
     * 超過255字元之字串類主鍵視為未命中且不送Jet(ok為1、n為0)，因Jet對超過255字元之字面值會截斷後比對，送出將刪除另一列
     * 註: 字串良構檢核(見類別註解)：主鍵含NUL或孤立代理者該筆ok為0並附err(invalid id: 原因 at [data[索引].主鍵欄]，不回顯值；原為靜默回ok為1)，
     * 同批其餘筆照常處理，且先於初始化(匯入model)，故全數不合格時不載入model、不開啟資料庫檔、不送Jet；刪除不檢資料欄位
     * 註: 本函數不受opt.autoGenPk影響，於任一設定下皆不補值
     * 註: 由DELETE語句自身之影響列數判定命中，不另行查詢以免多一次往返且與刪除間存在競態
     *
     * @memberOf WOrmMdb
     * @param {Object|Array} data 輸入數據物件或陣列，會查找各數據的opt.pk值，有存在者就刪除
     * @param {Object} [option={}] 輸入設定物件，預設為{}
     * @param {Object} [option.instance=null] 輸入實例instance物件，預設為null
     * @returns {Promise} 回傳Promise，resolve回傳與輸入等長之刪除結果陣列[{n,nDeleted,ok}]，reject回傳錯誤訊息
     */
    async function del(data, option = {}) {

        //check
        if (!iseobj(data) && !isearr(data)) {
            return []
        }

        //instance
        let instance = get(option, 'instance', null)

        //isErr, res
        let isErr = false
        let res = null

        //data為呼叫當下之快照(見snap), 其後檢核與刪除皆只使用此份
        if (!isarr(data)) {
            data = [data]
        }

        //chkWf, 主鍵(含NUL或孤立代理)之良構預檢, 須先於初始化(匯入model)、讀取與刪除; 不合格者該筆ok為0並附err, 不中斷同批其餘筆, 亦不送Jet
        let msgs = null
        try {
            msgs = chkWf(data, false)
        }
        catch (err) {
            emitError('del', data, err)
            return Promise.reject(err)
        }

        //rests, 逐筆結果, 未定案者為null
        let rests = map(msgs, (m) => {
            if (m === null) {
                return null
            }
            return {
                n: 0,
                nDeleted: 0,
                ok: 0,
                err: m,
            }
        })

        //nPend, 預檢後尚待處理之筆數, 為0則無需初始化與連線
        let nPend = size(rests.filter((v) => {
            return v === null
        }))

        //si
        let si = instance
        if (instance === null && nPend > 0) {
            si = await initAdodb()
        }

        try {

            //check, 全數於預檢即已定案
            if (nPend > 0) {

                //check
                if (si.err) {
                    throw si.err
                }

                //check, 確認model存在, 令資料表設定有誤時為整批性錯誤
                let md = getMd(si)
                let pkType = getMdPkType(md)

                //dels, 具有效主鍵者方送出刪除
                let dels = []
                each(data, (v, k) => {

                    //check, 預檢不合格者已定案
                    if (rests[k] !== null) {
                        return
                    }

                    //pkv, r
                    let pkv = get(v, opt.pk)
                    let r = normPk(pkv, pkType)

                    //check, 未帶有效主鍵者不補值亦不送查詢, 直接視為該筆無法處理
                    if (r.kind === 'invalid') {
                        rests[k] = {
                            n: 0,
                            nDeleted: 0,
                            ok: 0,
                            err: `invalid data[${k}].${opt.pk}`,
                        }
                        return
                    }

                    //check, 型別不符者為該筆無法處理
                    if (r.kind === 'mismatch') {
                        rests[k] = {
                            n: 0,
                            nDeleted: 0,
                            ok: 0,
                            err: `invalid data[${k}].${opt.pk}, type mismatch with pk column [${opt.pk}] in model [${opt.cl}]`,
                        }
                        return
                    }

                    //check, 不可能存在者為未命中且不送Jet(送出時Jet會截斷超長字面值而刪除另一列)
                    if (r.kind === 'cannot') {
                        rests[k] = {
                            n: 0,
                            nDeleted: 0,
                            ok: 1,
                        }
                        return
                    }

                    //寫回正規化值, 令事件之數據與實際送出者一致, 並定為唯讀
                    v[opt.pk] = r.v
                    lockPk(v)

                    dels.push({
                        k,
                        sql: getDeleteByPk(opt.cl, opt.pk, r.v),
                    })
                })

                //run, 各刪除彼此獨立故不中止
                if (size(dels) > 0) {
                    let r = await si.jet.run(map(dels, (v) => {
                        return {
                            type: 'execute',
                            sql: v.sql,
                            stopOnError: false,
                        }
                    }))

                    //check, 連線開啟重試耗盡影響本次操作之全部數據, 屬整批性錯誤而非逐筆失敗(T4)
                    if (r.openFailed === true) {
                        throw new Error(r.error)
                    }

                    each(dels, (v, j) => {
                        let rr = get(r, `results.${j}`, null)

                        if (rr && rr.ok) {

                            //nDel, n與nDeleted皆為主鍵命中筆數, 未命中為0且屬正常結果
                            let nDel = isnum(rr.n) ? rr.n : 0

                            rests[v.k] = {
                                n: nDel,
                                nDeleted: nDel,
                                ok: 1,
                            }
                            return
                        }

                        //rest, 本筆失敗不中斷整批
                        rests[v.k] = {
                            n: 1,
                            nDeleted: 0,
                            ok: 0,
                            err: getErrMsg(get(rr, 'error', 'can not delete data')),
                        }
                    })
                }

            }

            //res
            res = rests

        }
        catch (err) {
            isErr = true
            res = err
        }
        finally {

            //close, 關閉本次自行建立之實例(各實例自帶sequelize, 見R-LIFE)
            if (instance === null && si !== null) { //內部自動初始化得close
                await si.close()
            }

        }

        //check
        if (isErr) {
            emitError('del', data, res)
            return Promise.reject(res)
        }

        //emit, 逐筆失敗於各筆結果定案後依輸入順序發出, 且早於整批change
        each(res, (v, k) => {
            if (v.ok === 0) {
                emitError('del', [data[k]], v.err)
            }
        })

        //emit, 須於結果定案後發出
        emitChange('del', data, res)

        return res
    }


    /**
     * 依條件刪除多筆數據(破壞性操作，須審慎使用，非必要不用；刪除單筆請用del)，需與del分開，避免未傳數據導致直接刪除全表
     *
     * 使用須知:
     * 1. 不給條件即刪除全部數據: find未給、為undefined或為{}時，刪除資料表內全部數據，不另行確認。給了條件才是部分刪除。
     * 2. 傳了值卻不是條件物件(null、陣列含[]與[{...}]、字串、數值、布林、函數、Date、RegExp、Map、Set、類別實例等)
     *    一律整批reject，不視為{}，不刪除任何數據。
     * 3. 條件僅支援系列白名單: 欄位等值{欄:純量}(多欄為AND)、欄位運算子$eq $ne $gt $gte $lt $lte(值為純量)與
     *    $in $nin(值為純量陣列，各至多2000個元素)、文件層$and $or(值為條件物件之非空陣列，至多999項)。純量為字串、有限數字、布林、有效Date；
     *    null僅可用於欄位等值、$eq、$ne。白名單外之運算子($not $nor $regex $options $exists $where $expr $like $ilike等)、
     *    欄位層$and/$or、子查詢、函數值、Symbol鍵、undefined值、空的$nin/$and/$or等一律整批reject，
     *    訊息為invalid find: 原因 at [路徑]，且不刪除任何數據。
     * 4. 與select共用同一檢核與同一條件，select(find)命中之數據即本函數刪除之數據；建議先以select(find)確認命中範圍再刪除；
     *    整個find內相異主鍵值總數亦至多2000(跨陣列合計)；主鍵之$ne:null與其他欄位相同，意為[非NULL]，命中全部列；主鍵之範圍運算子依欄位型別比較(見select)。
     * 5. 條件值若來自可能為undefined、null或空陣列之變數，呼叫端須先自行判斷；undefined值會reject而非被忽略，
     *    空的$nin會reject，$in:[]則為恆假(刪除0筆)；注意delAll({pk:{$ne:變數}})於變數為null時等同全刪(非NULL主鍵之列全部命中，與非主鍵欄相同)。
     *    DATE欄之日期條件以牆上時間(浮動時間)比較，負偏移時區主機以DATE範圍條件刪除時亦不誤刪9999年末日之哨兵列(原已知限制LF8，第87項B4已解；見select之使用須知6.)。
     *    條件引用model宣告為非Jet可對應欄型(TIME、ENUM、JSON、BLOB等)之欄時整批reject，不刪除任何數據(見select之使用須知7.)。
     * 6. 語意差異(SQL式): $ne/$nin不命中NULL(三值邏輯)；字串比對不分大小寫(Jet)。需明確表達時可用可攜寫法:
     *    排除NULL為{$and:[{f:{$ne:null}},{f:{$ne:x}}]}，含NULL為{$or:[{f:null},{f:{$ne:x}}]}。
     *
     * 註: n與nDeleted皆為實際刪除筆數，兩者恆相等，n不得取全表筆數；條件無命中時回{n:0,nDeleted:0,ok:1}，不視為錯誤
     * 註: 僅[未給、undefined、無任何自有鍵之條件物件]視為無條件；條件之入口形狀檢核先於載入model、讀取與刪除，未通過者不開啟資料庫檔、不送SQL，
     * 以整批性錯誤reject(發出一次error事件，不發change事件)；欄位名或值型別不合者於讀取全表之後才由轉譯層reject，不刪除任何數據
     * 註: 帶條件時先以與select相同之記憶體過濾取得命中數據之主鍵清單，再依主鍵逐筆以DELETE … WHERE 主鍵 =刪除，
     * 令刪除範圍與select(find)之結果完全一致；若逕將條件送Jet，因Access不支援$in、$nin等運算子，
     * 會出現[select查得到但delAll刪不到]或反之之不一致
     * 註: 不用IN清單刪除，因Jet對長字串之IN與=不等價(已實測255個é之主鍵IN不中而=命中)，用IN會使命中之列刪不到
     * 註: 逐筆之DELETE於單次exe往返內以交易包覆，令任一筆失敗時整體回滾而不留下部份刪除
     *
     * @memberOf WOrmMdb
     * @param {Object} [find={}] 輸入刪除條件物件(系列白名單，規則見上)，不給予find則代表刪除全部數據，非條件物件或白名單外運算子整批reject
     * @param {Object} [option={}] 輸入設定物件，預設為{}
     * @param {Object} [option.instance=null] 輸入實例instance物件，預設為null
     * @returns {Promise} 回傳Promise，resolve回傳刪除結果{n,nDeleted,ok}，reject回傳錯誤訊息
     */
    async function delAll(find = {}, option = {}) {

        //instance
        let instance = get(option, 'instance', null)

        //isErr, res
        let isErr = false
        let res = null

        //si, inited為本次是否自行初始化(壞find不初始化, 故不得關閉他次呼叫所建之sequelize)
        let si = instance
        let inited = false

        try {

            //check, 條件之入口檢核為第一步, 先於初始化(匯入model)、讀取與刪除, 與select共用normFind, 其後只用複本(R-WL-01)
            let fd = normFind(find)

            //initAdodb
            if (instance === null) {
                inited = true
                si = await initAdodb()
            }

            //check
            if (si.err) {
                throw si.err
            }

            //check, 確認model存在, 令資料表設定有誤時為整批性錯誤
            getMd(si)

            //nDel
            let nDel = 0

            if (Reflect.ownKeys(fd).length === 0) {
                //無條件, 直接清空全表, 不需先取主鍵清單
                //註: fd為cvOrmFind之複本, 無自有鍵者僅限未給、undefined與{}(R-WL-02), 其餘一律經findAll

                let rr = await si.jet.execute(getDeleteAll(opt.cl))
                nDel = isnum(rr.n) ? rr.n : 0

            }
            else {
                //有條件, 以與select相同之過濾取得命中數據

                //rs
                let rs = await findAll(si, fd)

                //pkvs, 命中數據之主鍵
                let pkvs = []
                each(rs, (v) => {
                    let pkv = get(v, opt.pk)
                    if (!isEffPk(pkv)) {
                        //無有效主鍵者無從精確定位, 不得靜默略過而使刪除少於預期
                        throw new Error(`can not delete data without valid ${opt.pk}`)
                    }
                    pkvs.push(pkv)
                })

                if (size(pkvs) > 0) {

                    //cmds, 逐筆以=語句刪除, 不用IN: Jet對長字串之IN與=不等價(已實測255個é之主鍵IN不中), 改用IN會使命中之列刪不到
                    let cmds = map(pkvs, (v) => {
                        return {
                            type: 'execute',
                            sql: getDeleteByPk(opt.cl, opt.pk, v),
                        }
                    })

                    //run, 以交易包覆令任一筆失敗時整體回滾
                    let r = await si.jet.run(cmds, { useTransaction: true })

                    //check
                    if (!r.ok) {
                        throw new Error(r.error)
                    }

                    //nDel
                    each(r.results, (rr) => {
                        nDel += isnum(rr.n) ? rr.n : 0
                    })
                }
            }

            //res, 條件無命中時為0且屬正常結果
            res = {
                n: nDel,
                nDeleted: nDel,
                ok: 1,
            }

        }
        catch (err) {
            isErr = true
            res = err
        }
        finally {

            //close, 關閉本次自行建立之實例(各實例自帶sequelize, 見R-LIFE)
            if (inited && si !== null) { //內部自動初始化得close(si為null代表初始化未完成, 無從關閉)
                await si.close()
            }

        }

        //check
        if (isErr) {
            emitError('delAll', null, res)
            return Promise.reject(res)
        }

        //emit, 須於結果定案後發出
        emitChange('delAll', null, res)

        return res
    }

     * @returns {Promise} 回傳Promise，resolve回傳創建結果，reject回傳錯誤訊息

    async function createStorage() {

        //check, 已存在不重建
        if (fs.existsSync(opt.storage)) {
            return 'existed'
        }

        //create, 以ADOX建立新Jet4 mdb檔, 有密碼則建立加密檔

        try {
            await jet.create()
        }
        catch (err) {
            emitError('createStorage', null, err)
            return Promise.reject(err)
        }

        return 'created'
    }

    /**
     * 把一列攤平為只含自有資料屬性之純物件(第66項, 見CLAUDE_rulebook.md之R-WF-04)
     *
     * 註: 非物件原樣返回; 原型為Object.prototype或null之一般物件、原型為Array.prototype之陣列(cloneDeep後自有存取器已成資料屬性)已是純資料, 原樣返回;
     * 其餘(類別實例、Object.create(proto)、Array之子類別、Map與Set等內建容器及其子類別、自訂Symbol.toStringTag之物件等)取:
     * 全部可列舉屬性(自有與繼承, for in)、原型鏈上(不含Object.prototype與Array.prototype)之存取器屬性(含不可列舉之類別getter, 現況即會被取值寫入),
     * 每個名稱只讀一次(存取器只呼叫一次, 之後的檢核、預讀、更新與事件皆讀此固定值; 主鍵欄與其他欄位同, 第一次回undefined者亦固定為undefined), 方法與其他原型上之資料屬性不取
     * 註: 值之取得: 自有資料屬性已由外層cloneDeep複製, 直接採用(不重複複製, 亦不改變其對Error、函式、Promise等不可複製值之處置);
     * 繼承而來或存取器回傳之值以{x:值}包一層再cloneDeep取出(與外層cloneDeep對巢狀值之語意相同: 不可複製之值原樣保留)
     * 註: 取值拋錯者(如與model無關之getter拋錯)不立即失敗, 改定義為會重新拋出同一錯誤之不可列舉存取器: 僅在該欄位真被讀取(model之欄位)時才拋出, 與修改前相同;
     * 但鍵名本身不良構者改定義為可列舉之undefined資料屬性, 令chkOrmData仍檢出該鍵名
     * 註: 內建容器(Map、Set等)與自訂標籤之物件(Object.prototype.toString之標籤不是Object)另把複製後之原物件以Symbol鍵(KEY_CONT, 不可列舉)附在攤平列上,
     * 令chkWf仍以chkOrmData走訪其內容(Map之項目、Set之元素等); 寫入只用攤平後之列
     * 註: 令呼叫端其後改動原型或繼承值、存取器每次回傳不同值或其副作用改動同列其他欄位(含主鍵), 皆不影響檢核與寫入之值
     * 註: 以defineProperty定義, 避免名稱為__proto__時改動原型
     *
     * @ignore
     * @param {*} v 輸入一列數據(已cloneDeep)
     * @returns {*} 回傳攤平後之列
     */
    function flatRow(v) {
        if (v === null || typeof v !== 'object') {
            return v
        }
        let proto = Object.getPrototypeOf(v)
        if (isarr(v)) {
            if (proto === Array.prototype) {
                return v
            }
        }
        else if (proto === Object.prototype || proto === null) {
            return v
        }
        let names = new Set()
        for (let k in v) {
            names.add(k)
        }
        for (let p = proto; p !== null && p !== Object.prototype && p !== Array.prototype; p = Object.getPrototypeOf(p)) {
            for (let k of Object.getOwnPropertyNames(p)) {
                let d = Object.getOwnPropertyDescriptor(p, k)
                if (k !== 'constructor' && d !== undefined && typeof d.get === 'function') {
                    names.add(k)
                }
            }
        }
        let o = {}
        for (let k of names) {
            let x
            try {
                let d = Object.getOwnPropertyDescriptor(v, k)
                if (d !== undefined && 'value' in d) {
                    x = d.value
                }
                else {
                    x = cloneDeep({ x: v[k] }).x
                }
            }
            catch (err) {
                if (chkOrmStr(k, { nul: false }) !== null) {
                    Object.defineProperty(o, k, { value: undefined, writable: true, enumerable: true, configurable: true })
                }
                else {
                    Object.defineProperty(o, k, {
                        get() {
                            throw err
                        },
                        enumerable: false,
                        configurable: true,
                    })
                }
                continue
            }
            Object.defineProperty(o, k, { value: x, writable: true, enumerable: true, configurable: true })
        }
        if (!isarr(v) && Object.prototype.toString.call(v) !== '[object Object]') {
            Object.defineProperty(o, KEY_CONT, { value: v, writable: false, enumerable: false, configurable: false })
        }
        return o
    }


    //snap, 數據於呼叫當下即同步複製並攤平各列(第66項, 見CLAUDE_rulebook.md之R-WF): useStable時各函數經佇列延後執行(pmQueue於執行前delay),
    //若於函數內才複製, 呼叫端於呼叫後立即改動原數據(如重用同一陣列、改動共用之原型)會影響實際檢核與寫入之值; insert、insertBulk、save、del只使用此複本,
    //檢核與寫入皆作用於同一份複本; 複製或攤平拋錯(如存取器拋錯)與函數內之其他錯誤同為rejected promise(不發error事件, 同複製前之行為)
    //外層批次以索引迴圈建成普通陣列: 不採用輸入陣列(或其子類別)自帶之map/Symbol.species, 以免批次被改變型別或靜默變成零筆; 洞視同undefined(同修改前lodash map之走訪)
    //既有之[無資料]判定(非物件、空物件、空陣列)須以cloneDeep後之原輸入為準而先於攤平: 攤平會把只有無關getter之物件變成非空, 使原本不處理之輸入多出一列
    let snap = (fn) => {
        return function(data, ...rest) {
            let d
            try {
                d = cloneDeep(data)
                if (iseobj(d) || isearr(d)) {
                    if (isarr(d)) {
                        let a = []
                        for (let i = 0; i < d.length; i++) {
                            a[i] = flatRow(d[i])
                        }
                        d = a
                    }
                    else {
                        d = flatRow(d)
                    }
                }
            }
            catch (err) {
                return Promise.reject(err)
            }
            return fn(d, ...rest)
        }
    }


    //bind
    ee.createStorage = createStorage
    ee.genModelsByTabs = genModelsByTabs
    ee.init = initAdodb
    if (opt.useStable) {
        //用佇列(同時最大執行數1且先進先執行)處理高併發之情形
        //若沒管控, access mdb於同一行程內併發操作有機會出現非預期錯誤
        ee.select = function() {
            return pmq(select, ...arguments)
        }
        ee.selectByPk = function() {
            return pmq(selectByPk, ...arguments)
        }
        ee.insert = snap((...args) => {
            return pmq(insert, ...args)
        })
        ee.insertBulk = snap((...args) => {
            return pmq(insertBulk, ...args)
        })
        ee.save = snap((...args) => {
            return pmq(save, ...args)
        })
        ee.del = snap((...args) => {
            return pmq(del, ...args)
        })
        ee.delAll = function() {
            return pmq(delAll, ...arguments)
        }
    }
    else {
        ee.select = select
        ee.selectByPk = selectByPk
        ee.insert = snap(insert)
        ee.insertBulk = snap(insertBulk)
        ee.save = snap(save)
        ee.del = snap(del)
        ee.delAll = delAll
    }

    return ee
}
